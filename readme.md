# Rahi Equestrian - React Application

This is the converted React.js + Tailwind CSS application for Rahi Equestrian.

## Project Structure
- `src/components`: Reusable UI components (Navbar, Hero, Services, etc.)
- `src/pages`: Page components (Home, CategoryPage)
- `src/layouts`: Main layout wrapper
- `src/hooks`: Custom hooks (useTheme)
- `src/utils`: Utilities (ScrollToTop)
- `public/images`: Static assets

## Getting Started

1.  **Install Dependencies** (if not already done):
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Features
- **React 18 + Vite**: Fast performance and modern tooling.
- **Tailwind CSS**: Utility-first styling with custom configuration.
- **Responsive Design**: Mobile-first approach with extensive responsiveness.
- **Dark Mode**: Integrated theme toggle with persistence.
- **Routing**: `react-router-dom` with hash link support for on-page navigation.
- **SEO**: `react-helmet-async` for meta tag management.
